# ГИБДД-Очевидец

Android-приложение очевидца для анонимной отправки сообщений сотрудникам ГИБДД. Репозиторий содержит только клиент роли **Очевидец**; приложение сотрудника разрабатывается отдельно.

## Стек

- Kotlin, Jetpack Compose, Material 3;
- Navigation Compose;
- Retrofit, OkHttp, Gson;
- Yandex MapKit;
- Coil для фото и GIF;
- Media3 ExoPlayer для видео;
- Android Keystore для защищённого хранения сессии;
- minSdk 26 (Android 8.0).

## Реализовано

- приветственный экран и единый непрерывный чат;
- анонимная регистрация устройства по SHA-256 fingerprint;
- повторная регистрация с сохранением `device_id` и обновлением `access_token`;
- защищённое хранение `device_id` и токена через Android Keystore;
- отправка и получение текстовых сообщений;
- загрузка фото, видео и GIF с ограничениями размера из ТЗ;
- выбор медиа через Photo Picker, пять последних фотографий и съёмка камерой;
- восстановление медиа из истории после перезапуска приложения;
- полноэкранный просмотр фото/GIF и воспроизведение видео;
- отправка текущего местоположения;
- выбор статической точки на Яндекс Картах и поиск адреса;
- live-геолокация на 15 минут с отправкой точки каждую секунду и досрочной остановкой;
- группировка сообщений по дням и отображение локального времени;
- статусы для текста, медиа и статической точки: одна галочка — сервер принял сообщение, две — заполнено `delivered_at`;
- обновление истории чата опросом backend каждые 5 секунд;
- foreground-service и уведомление во время live-геолокации.

## Backend

Тестовый API по умолчанию:

```text
http://193.124.115.164:4401/
```

Сейчас сервер использует HTTP, поэтому для тестовой сборки разрешён cleartext traffic. Другой адрес можно передать через Gradle property; URL должен оканчиваться `/`:

```powershell
.\gradlew.bat :app:assembleDebug -PAPI_BASE_URL=https://server.example.ru/
```

Клиент использует заголовки:

```http
X-Client-App: eyewitness
Authorization: Bearer <access_token>
```

Подключены регистрация, история чата, текст, статическая и live-геолокация, загрузка/скачивание медиа и `delivered_at`. Медиа хранится на backend семь дней с момента последнего скачивания.

## Настройка Яндекс Карт

Добавьте ключ MapKit только в локальный `local.properties`:

```properties
MAPKIT_API_KEY=your_mapkit_key
```

`local.properties` исключён из Git и не должен попадать в коммит.

## Запуск

1. Открыть корень репозитория в Android Studio.
2. Добавить `MAPKIT_API_KEY` в `local.properties`.
3. Дождаться Gradle Sync.
4. Запустить конфигурацию `app` на устройстве или эмуляторе с Android 8.0+.

Сборка из PowerShell:

```powershell
.\gradlew.bat :app:assembleDebug
```

Debug APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`.

## Структура

- `core/network` — Retrofit API и авторизационные заголовки;
- `core/storage` — защищённая сессия устройства;
- `data` — реализации репозиториев;
- `domain` — модели и интерфейсы репозиториев;
- `feature/chat` — чат, вложения и отображение сообщений;
- `feature/location` — карта, статическая и live-геолокация;
- `ui` — тема и общие Compose-компоненты.

## Ещё не реализовано

- WebSocket и push-события — пока используется polling;
- offline retry через одну минуту и локальная очередь;
- временный и постоянный бан;
- push-уведомления о новых сообщениях.

Эти возможности требуют следующих backend-контрактов или отдельного этапа реализации.
