# ГИБДД-Очевидец

Android-приложение для анонимной отправки сообщений сотрудникам ГИБДД о возможных правонарушениях. Это отдельный клиент для роли **Очевидец**; приложение сотрудника и его ролевой функционал находятся вне данного репозитория.

## Технологии

- Kotlin
- Jetpack Compose + Material 3
- Navigation Compose
- Retrofit + OkHttp
- Android Keystore
- Coil
- minSdk 26 (Android 8.0)

## Реализовано

- WelcomeScreen по макету Figma;
- навигация между приветствием и единым чатом;
- базовый ChatScreen с входящими и исходящими сообщениями;
- цвета, типографика и компоненты дизайн-системы;
- окно вложений с вкладками «Галерея» и «Геолокация»;
- выбор фото, видео через системный Photo Picker;
- отображение пяти последних фотографий из MediaStore;
- съёмка фото и видео через системное приложение камеры;
- проверка формата и размера файлов;
- локальный предпросмотр и медиасообщения со статусом ожидания;
- подготовленный API-клиент регистрации очевидца;
- SHA-256 fingerprint устройства;
- fallback UUID;
- зашифрованное хранение `device_id` и `access_token` через Android Keystore.

## Backend

Сейчас backend реализует регистрацию устройства:

```http
POST /api/v1/devices/register
X-Client-App: eyewitness
```

Интеграционный слой подготовлен, но регистрация пока не вызывается из UI: для работы требуется доступный Android-устройству адрес backend.

По умолчанию debug-сборка использует локальный адрес Android Emulator:

```text
http://10.0.2.2:8001/
```

Публичный HTTPS URL передаётся через Gradle property:

```powershell
.\gradlew.bat assembleDebug -PAPI_BASE_URL=https://server.example.ru/
```

URL должен заканчиваться символом `/`.

## Запуск

1. Открыть корень проекта в Android Studio.
2. Дождаться завершения Gradle Sync.
3. Запустить эмулятор или устройство с Android 8.0+.
4. Выбрать конфигурацию `app` и нажать Run.

Локальная сборка из PowerShell:

```powershell
.\gradlew.bat :app:assembleDebug
```

Unit-тесты:

```powershell
.\gradlew.bat :app:testDebugUnitTest
```

## Пока не подключено

- отправка текста и медиа на сервер;
- WebSocket и real-time сообщения;
- статическая и live-геолокация;
- Room и offline retry;
- статусы доставки от backend;
- push-уведомления;
- временный и постоянный бан.

Эти функции требуют соответствующих backend-контрактов и будут подключаться отдельными этапами.
